2. **會計約束對「有多少外資必須在 cohort 外」有實質識別力**:37.5%(量加權

   ——A3 是 gross 覆蓋率的補數(口徑=S/F 那一類),本數字是非負性推出的下界。
   兩者不可互相取代,引用時要指明是哪一個。
3. **T1 幾乎看得到全部市場成交**(未觀測 0.11%),所以 feasible set 分配到
   可見席位時不需要額外的「未觀測桶」;但仍照 §5.1 顯式存欄,不靠假設。

### 2.3 條件分布:三個 primitive 全部帶機械成分

  不能直接讀成「集中決策」。對 log_gross 則非單調(U 型,兩端小樣本)。
- **directional_ratio 對 breadth 單調下降**:[10,100) 0.188 → [600,900)
  0.053。**碰得多必然看起來中性**(客戶數多→買賣相抵),與規模的關係

→ 三者都必須條件化後才能當行為讀。這是 §4.2「raw value 與 behavior 不等價」

## 5. 兩個施工期錯誤(2026-09-20 自我複查抓到,已修)

### 5.1 外資 cohort 代號填錯(我的錯,影響全表)

首版 `FOREIGN_BROKER_CODES` 把 **9200/9100 填成港商野村/港商麥格理,實際上
9200=凱基、9100=群益金鼎**(兩個本土券商總公司)——當初查詢輸出被截斷,
我憑印象補了兩個代號沒回頭核對。真代號是 1560(港商野村)、1360(港商麥格理)。

後果:cohort 混入兩個大型本土 HQ、漏掉兩個真外資席位。聯鈞 2026-09-14 買方
cohort 從錯的 1,318 張變成正確的 1,082 張。總量層級因兩邊大致相抵而影響小
(HiddenForeign 0.372→0.375、S/F 0.634→0.626),**但個股層級會完全錯**。

修法不只是改數字:名單改成 `FOREIGN_BROKER_NAMES` 代號→名稱 dict,建表入口
強制呼叫 `assert_cohort_names` 對當期資料驗證,對不上當場 raise;另加回歸測試。
**代號必須自資料查得,不得憑印象填**——這條寫進 docstring。

### 5.2 TEJ vol 在兩天全市場性偏低(資料事件,非計算錯誤)

全年 5,173 列(0.8%)T1 超過 TEJ vol 逾 1 張容差,**全部集中在 2026-05-05
(當日 84% 股票)與 2026-07-17(49%)**。原始 fugle shard 無重複列、買賣總
內部自洽(2330@07-17 買=賣=95,833 張 vs TEJ vol 74,514 張,差 28%),且該日
TEJ `trn` 成交筆數 47,404 異常低於鄰日(79k/98k/188k)——指向 TEJ 當日資料
不完整,不是 broker_tx 膨脹。

這修正了帳本 A5 的「零超出」:A5 只普查六日,全年尺度上有兩天破裂。影響:
那兩天的 V 偏低會讓 L=max(0,S+F−V) 虛高,故整日界限不發布
(`bounds_publishable=False`)。已入 audit_ledger A6。
