## 0. 設計原則(這輪學到的,三條)

1. **一欄一問**:每個基礎欄位要能用一句話說它回答什麼。多重性違反(三問合一,
   而且 99% 的區分力來自集中度單一零件:AUC 0.828 vs 0.819)。
2. **夠原始**:基礎欄位不預先混入另一個維度。廣度原值違反(與 log 碰幾檔相關
   0.77,大小與形狀已混在一起);有內容的是「同規模下的廣度殘差」,那是第二層。
3. **第二層對著問題算,不進表**:殘差、相對自身基線的偏離、合併分數,都在讀的
   時候算。滾動平均違反(與席位全年均值相關 0.98,是一種第二層卻被固化)。

## 2. 問題 → 基礎欄位 → 聚合(四題,按這輪證明重要的順序)

### Q-A 黑箱多大:某檔股票某天,官方外資/投信/自營的量有多少看得見、多少藏在本土席位?

- **粒度**:股票×日(T3 的粒度;2026 約 40 萬列/年,小)。
- **基礎欄位**(新表 `t3b_visibility`,或 T3 加欄):
  `foreign_seat_buy_sh / sell_sh`(12 個外資名字席位加總;**排除**國票-敦北
  法人——它是本土法人部,現行「法人」規則把它算進 institutional,做覆蓋率會
  高估),`hq_buy_sh / sell_sh`(無 dash 總公司加總),`branch_buy_sh / sell_sh`
  (分行加總),`total_buy_sh`(= 全部分點,對 TEJ vol 已閉環)。
- **聚合(第二層,讀時算)**:
  - 覆蓋率 = foreign_seat / official_foreign(買、賣分開)。
  - 隱藏外資量 = official_foreign − foreign_seat(F5:聯鈞 9/14 買 ~1,950 賣 ~2,100 張)。
  - 會計恆等式:other = total − 官方四桶(聯鈞 9/14 other = 8,429 張,71%)。
  - 總公司上限 = hq − (投信+自營官方量)= 總公司裡「不是投信自營」的量下界。
- **回答**:黑箱的大小與位置(在總公司還是分行),逐股逐日。**這是目前最便宜、
  最直接對到聯鈞問題的表**,不需要任何相似度。
- **資料形狀注意**:T1 全年 1 億列 group_by(股票,日,cohort)→ 逐月切塊;
  T3 側必須過濾股票代號(F9)。

### Q-B 這是什麼錢:某席位某天整日的錢,分法像哪個官方桶?

- **粒度**:席位×日(t4 的粒度;14.5 萬列/年)。
- **基礎欄位**(t4 v3 新增,取代現行 foreign_sim/fund_sim 排名版):
  `cos_foreign_buy / cos_foreign_sell / cos_fund_buy / cos_fund_sell /
  cos_prop_self_buy / … / cos_prop_hedge_sell`(對四個官方桶的金額 cosine,
  買賣各一,共 8 欄)+ `cos_market_buy / cos_market_sell`(對市場成交金額)。
  一欄一問:「今天的錢分法像不像 X 的分法」。
- **聚合(讀時算)**:
  - 殘差版:cos_X − f(cos_market)(F4 的 AUC 0.919 就是這個)。
  - 偏離版:今天 − 自身 60 日均(F3/廣度是 72% 性格,cosine 是否也是,待量)。
  - 席位類型:(碰幾檔, cos_market) 二維——同規模下異常像市場 = 掃市場型。
- **回答**:元大總公司 9/14 的錢像外資、像避險、還是像市場;哪些總公司像投信。
  **不能回答**逐股歸因(那是 Q-A 的會計恆等式 + 之後的 NNLS)。
- **資料形狀**:cosine 需席位×股票×日的金額 → 逐月切塊(同現行 t4 build);
  自營兩桶無分點錨,cos_prop_* 只能描述、不能校準——輸出時標 `unanchored`。
- **校準錨**(改 schema 前必過):全年重跑,12 外資席位 + 匯立為正錨、分行為
  負錨,cos_foreign 殘差 AUC ≥ 0.85;cos_fund 殘差保持 ≥ 0.75。

### Q-C 今天怎麼做的:某席位某天,偏一邊?集中?同一批人?

- **粒度**:席位×日。
- **基礎欄位**(已有,保留,各自獨立):`directional_ratio`(偏一邊,84% 當天)、
  `top5_share` / `top1_share`(集中,53% 性格)、`basket_self_sim`(同一批人,
  66% 當天)、`n_symbols`、`gross_amt`。
- **刪除**:`multiplicity`(F7:三問合一且 ≈ top5_share)、`*_20d/60d`(冗餘)、
  `foreign_sim_*` / `fund_sim_*` 排名版(F3:≈ 碰幾檔)。若要保留「廣度」,改為
  單一欄 `breadth` = 對市場成交金額的 rank corr(不再對外資/投信各算一份),
  讀時對 n_symbols 做殘差。
- **懸置**:`sector_hhi / top_sector / daytrade_assoc`——無問題待答;v3 不帶,
  等有問題再回來(成本零)。

### Q-D 誰在這檔股票上做了什麼:某席位在某檔股票某天

- **粒度**:席位×股票×日(T1 本身,1 億列/年,**不新建表**,讀時從 T1 取單一
  股日)。
- **聚合(讀時算,讀本用)**:
  - 當日在此股佔該席位當日 gross 的比例(T1 gross ÷ t4 gross_amt):摩根大通
    9/14 在聯鈞 10.3 億是它 1,507 檔裡的多大一塊。
  - 當日來回率 = min(buy, sell) / max(buy, sell):元大總公司 1,602/1,504 →
    94%;對照官方當沖佔比 68.5%,回答「誰在當沖聯鈞」——比 daytrade_assoc
    (席位整體)直接得多。
  - 席位在此股的淨額 vs 該席位整日的方向一致(Q-C):在聯鈞賣、整日也偏賣 =
    整體減碼;在聯鈞賣、整日偏買 = 換股。

  分散在許多分行,席位層級看不見,只能靠 Q-A 的量。**我押後者機率 60%**(分行
  買了 8,040 張,基數大)。
