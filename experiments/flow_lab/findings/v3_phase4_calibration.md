# v3 Phase 4:官方配置關聯與 cohort 驗證(2026-09-21)

依 ws-quant `docs/actor_layer_v3_architecture_alignment_2026-09-18.md` §8。
純邏輯在 `measure/allocation.py`(全 universe cosine)+ `measure/calibration.py`
(殘差化、分群 bootstrap、holdout 切分)。

## 0. 驗收對象是什麼、不是什麼(§8 開宗明義)

> 驗收對象是**配置關聯及既有 cohort 區分力**,不是未觀測投資人身份的正確率。
> **本土席位不是已知「非外資投資人」負樣本。**

這句話決定了整個 Phase 的語言:

- 可以說:「cos_foreign 殘差能區分 **foreign-broker cohort** 與其他席位」。
- **不可以說**:「這個量能辨識外資投資人」。本土席位裡本來就有外資的錢
  ——Phase 1 的硬界限已證明**至少 37.5% 的官方外資買量必須在 11 家外資
  席位之外**。所以「本土席位 = 負樣本」這個標籤本身帶著已知的污染,
  AUC 只能讀成「對行政 cohort 的區分力」,且**很可能被低估**(非嚴格下界——
  被污染的負樣本若本來就在低分端,拿掉反而降 AUC;09-21 外部審查指正,撤回「下界」)。
- 自營兩桶無席位身份 anchor → 只報配置關聯與缺口,標 `unanchored`;
  `unanchored` **不等於不能算**,只是不能校準。

## 1. 設計:五個必做的控制(§8 逐條)

1. **同側 market cosine + gross + breadth 控制**:殘差後是否仍有資訊。
   Phase 2 已證 cos_market 本身 59% 是席位長期性格,故控制項要含席位規模
   與廣度,否則「像外資」會退化成「掃得寬」(O1 的原始錯誤)。
2. **時間 holdout**:前 2/3 訓練、後 1/3 測試(**不打散**,金融面板打散
   = 前視)。所有殘差化的係數只在訓練期估。
3. **leave-one-broker-family-out**:11 家外資席位不是 11 個獨立樣本——
   同一集團(如摩根系)行為相關。逐家留一,看區分力是否靠單一家撐起。
4. **買賣兩側分開**:§7 已證兩側 cos_market 僅相關 0.49,不得假設對稱。
5. **穩健性**:剔 2330、剔當日成交額前五、只看小額席位、跨月穩定性。

**不確定性**:同一席位連續日**不是獨立樣本**(Phase 2 已量:cos_market 的
席位固定效果占 59%)。故 bootstrap 以 **席位為單位重抽**(block bootstrap),
不是逐列重抽——逐列會把信賴區間縮到假的窄。

## 2. 預期(2026-09-21 凍結,跑數據前)

### E1 全 universe 定義下,O1 的探針結論還站得住嗎?

O1 用 support-restricted cosine、單月、未控 gross/breadth,得 AUC 0.919。
換成**全 universe 定義 + 全年 + 控制三項**後:

- 預期 cos_foreign 殘差的 **AUC 0.75-0.88**(比 O1 低,因為控制變多、
  定義更嚴);**若 < 0.65** 代表 O1 的高分主要來自 support-restricted 的
  分母效應,那個結論要撤回。
- 預期 **buy 與 sell 的 AUC 差 < 0.08**(兩側都該有,只是強弱不同)。

### E2 時間 holdout 與 family holdout

- 時間 holdout:測試期 AUC 比訓練期掉 **< 0.05**。若掉 > 0.10,代表殘差化
  的係數不穩定(市場結構在年內變化),需改滾動估計。
- leave-one-family-out:**11 次留一中,至少 9 次 AUC > 0.70**。若某一家
  拿掉就崩(< 0.60),代表區分力靠它單獨撐起,結論要限縮到那一家。
- 我押**最可能撐起分數的是大五家**(摩根大通/高盛/摩根士丹利/瑞銀/美林),
  因為它們掃市場最寬;**小額台(匯豐/法巴/大和)留一影響最小**。

### E3 投信與自營

- cos_fund 殘差的 AUC(仍以 foreign cohort 當正樣本)預期 **0.55-0.70**
  ——O1 時代 fund_sim 的 d=1.65 看似很強,但那是未控 gross/breadth 的版本;
  控制後應大幅縮水。**這一格是 O1 最可能被推翻的結論。**
- cos_prop_self / cos_prop_hedge:**無席位 anchor,不報 AUC**,只報
  ①與 market cosine 的相關 ②權證發行商總公司(元大/凱基/群益/統一)的
  cos_prop_hedge 是否高於非發行商——這是自營桶唯一能間接驗的東西。
  預期發行商高於非發行商,差距 **> 0.05**;若不成立,自營桶標
  `unanchored` 且讀本不呈現。

### E4 market_rank_alignment 的增量(§8 點名)

- 比較「amount cosine + gross + breadth」與「再加 rank alignment」。
- 預期 rank 的增量 AUC **< 0.02**(Phase 1 已證它與 log breadth 相關 0.77,
  資訊應被 breadth 吸收)。**若增量 > 0.05**,則 Phase 1「rank 版應退役」
  的判斷要翻案,rank 欄位要留在 T4 v3。

### E5 不確定性的尺度

- 席位層 block bootstrap 的 AUC 95% 區間寬度預期 **0.08-0.20**(11 個外資
  席位是很小的有效樣本)。
- **若逐列 bootstrap 的區間寬度 < 席位層的 1/3**,即證實「同席位連續日當
  獨立樣本」會把不確定性低估一個數量級——這是要寫進證據卡的方法論警語。

測試期 = 後 1/3(**不打散**);殘差化係數只在訓練期估。

### 3.3 四個值得記的發現

**一、小額外資台是倒扣,不是「影響最小」。** 留一結果:拿掉美林/摩根大通/
瑞銀,AUC 掉到 0.813-0.815(它們在撐);拿掉**大和國泰 AUC 反而升到 0.880**、
匯豐 0.835、法巴 0.834(它們在拖)。複查補做量化了這件事:**只留 4 家小額
外資台為正樣本,AUC 掉到 0.656(買)/ 0.594(賣)**。與 O1「外資席位是兩群人」
互證:大五家掃市場的配置像官方外資,小額客戶台的配置只略像——**證據卡的
0.828 是混合後的數字,對小額台是高估**。另,11 家外資席位**全部**在席位
規模的上半,§8.3「小額席位是否仍成立」無法用規模切分直接測,只能用
cohort 內的小台代替。

**二、殘差化讓買側 AUC 上升(測試期 raw 0.783 → 殘差 0.828),不是下降。**
(首版寫 0.776 是全樣本 raw 對測試期殘差,母體不同,已修正為同母體。)
我原以為控制愈多分數愈低。實際上席位日層級 cos_foreign 對 cos_market 的
斜率 β ≈ **1.03**——兩者幾乎同步變動(O1 已證官方外資向量與成交量向量
Spearman 0.866),扣掉市場成分後殘差反而更乾淨地分開兩群。**補做的剔 2330
變體是這件事的直接證據**:raw AUC 從 0.783 掉到 0.656(raw 訊號重度依賴
台積電),殘差 AUC 只從 0.828 到 0.790(殘差不依賴)。這也解釋了 O1 為何
靠 support-restricted 版就能拿到 0.92:那個版本無意間部分抵銷了市場成分。

**三、逐列 bootstrap 把外資桶的不確定性低估 5.3-5.8 倍**(區間寬度 0.041
vs 0.216)。但這個倍數**不是普適的**:fund 與 prop_hedge 只有 1.0-1.6 倍,
因為它們訊號弱、席位間變異相對小。**「同席位連續日不是獨立樣本」的代價
與訊號強度成正比**——訊號愈強的桶,錯誤的 bootstrap 愈危險。

**四、我自己犯了規格 §8.3 第八條要防的錯。** 卡四首版拿發行商總公司的 raw
cos_prop_hedge 均值比其他本土席位,得 +0.158,寫成「遠超預期」。但發行商
總公司是全市場最大的四個席位(log_gross 中位 10.40 vs 9.01),而 Phase 2 已證
cos_market 有 59% 是席位規模性格——**我在同一份文件的卡一裡強調要控規模,
到卡四卻忘了**。控制後效應剩三分之一(+0.058/+0.081),同規模對照剩
+0.045/+0.054。這條要記:**「控制規模」不是對某一張卡做的事,是對每一個
跨席位比較都要做的事。**

### 3.4 market_rank_alignment 的去留(§8 點名)

**09-21 複查改寫。** 首版的 0.838/0.832 是 REPL 一次算的、repo 無程式,且只在
7-9 月(= 測試期)上比較——等於在 holdout 上挑欄位,違反 §8。現以
`v3_phase4_rank_align.py` 取代:rank_align 全年逐月重算;cos_foreign 與
rank_align **都先對三個控制項殘差化**(係數訓練期估),再比「cos 殘差之上,
加 rank 殘差有沒有增量」;**決定在訓練期做**,測試期只事後確認。

| 模型(殘差之上的線性分數) | 訓練期 AUC(決定) | 測試期 AUC(確認) |
|---|---|---|
| 買:cos_foreign 殘差 | 0.738 | 0.807 |
| 買:+ rank_align 殘差 | 0.751(**+0.014**) | 0.832(+0.026) |
| 賣:cos_foreign 殘差 | 0.761 | 0.772 |
| 賣:+ rank_align 殘差 | 0.761(**0.000**) | 0.772(0.000) |

rank_align 殘差單獨的 AUC 只有 0.585(買)/ 0.531(賣);與 log_n 相關
0.75/0.71。增量低於預先凍結的 0.02 門檻(買側測試期 0.026 略超,但遠低於
翻案門檻 0.05,且決定不看測試期)。Phase 1「rank 版應退役」**維持**:T4 v3
不收此欄;若日後有「明確且不可替代的描述問題」再議(§8 保留條款)。

本表的 cos 殘差 AUC 與卡一的 0.828 不同,因樣本限制在 rank_align 可算的
席位日(support ≥ 門檻,n=139,034),不是同一母體;結論只看同表內的增量。

**一個順手撞到、必須記的事實:`is_foreign ~ log_gross + log_n` 的線性監督
分數 AUC = 0.993**(訓練/測試皆是)。11 家外資席位就是最大的一批席位——
任何沒殘差化的跨席位比較,量到的都是規模。這也是本 Phase 所有 AUC 只能
讀成「線性控規模後的殘差區分力」的原因;非線性的規模效應未排除,更嚴的
做法是同規模對照(卡四已用),外資桶未做。
