## 2. Phase 2:α_b 跨年穩,γ_t 吃掉了年份

| 目標 | α 自身變異(2025 / 2026 / 合併) | γ(2025 / 2026 / 合併) | 順序 B α 增量(2025 / 2026) |
|---|---|---|---|
| top5_share | 71.5% / 78.3% / 67.0% | 9.8% / 11.3% / 15.7% | 54.8% / 57.2% |
| directional_ratio | 24.5% / 24.1% / 23.2% | 11.1% / 14.9% / 12.8% | 25.8% / 25.7% |
| cos_market_buy | 42.0% / 59.3% / 40.8% | 23.2% / 14.1% / **26.1%** | 36.1% / 46.4% |
| basket_self_sim | 24.0% / 33.8% / 23.5% | 7.9% / 7.0% / 9.4% | 27.5% / 34.2% |

- **trait 的判定跨年不變**:top5 是 trait(α 55-57%)、directional 與 basket
  是 state(α 26-34%),兩年各自估、合併估,排序一樣。
- **γ_t 在合併估時膨脹**(cos_market 14-23% → 26%),且 corr(γ, 當日市場量)
  從單年 0.33-0.50 升到 **0.665**:兩年量能差 2-3 倍,合併估時「年份」被
  γ_t 吸收——這是對的行為(§6 說 γ_t 是共同日狀態),但意味**合併估的 α_b
  是「跨兩種市況的平均性格」**,若席位性格隨市況變,合併會抹平它。
  cos_market 的 α 2026(59%)明顯高於 2025(42%),就是這種變化的痕跡。
- ε lag-1 自相關 0.27-0.32(top5)、0.16-0.25(其他)兩年同量級:滾動 baseline
  的必要性不是單年現象。
- 條件化格:2025 用 2026 定的 size_edges 有格子只 1 筆(2025 席位較小)。
  格邊界應按年份分位重定,本輪未改,α/γ 主結論不受影響(順序 B 兩年一致)。

## 4. Phase 4:跨年 OOS 比年內 OOS 掉 0.03-0.08,但外資桶仍分得開

係數在 2025 全年估,AUC 在 2026 全年讀(席位層 bootstrap 95% CI):

| 桶 | 側 | raw 2026 | **殘差 2026(係數 2025)** | CI | 2025 年內切分(對照) | 2026 年內切分(首版) |
|---|---|---|---|---|---|---|
| foreign | buy | 0.776 | **0.737** | [0.585, 0.857] | 0.827 | 0.823 |
| foreign | sell | 0.831 | **0.814** | [0.696, 0.895] | 0.846 | 0.789 |
| fund | buy/sell | 0.657 / 0.664 | 0.519 / 0.459 | — | 0.519 / 0.533 | 0.523 / 0.525 |

| prop_hedge | buy/sell | 0.667 / 0.673 | 0.588 / 0.566 | — | 0.677 / 0.537 | 0.591 / 0.628 |

- **外資桶跨年成立**:0.737 / 0.814(m2 物化表;首版快取 0.747 / 0.823,09-21
  重跑取代),CI 下界 0.59 / 0.70,遠離 0.5;反向(係數 2026 → 2025)0.816 / 0.749,
  對稱。**買側跨年掉得比賣側多**(0.823 → 0.737),且殘差化在跨年時**沒有**像
  年內那樣提升 AUC(raw 0.776 → 0.737):
  2025 估的截距與係數帶到 2026 有偏——β_mkt 1.094 vs 1.013、β_gross 相近,
  差在截距(2026 cos_market 整體高 0.1)。逐月看更清楚:2026 上半年 0.665-
  0.762,8-9 月 0.830 / 0.814——**離訓練期越遠反而越好**,說明不是漂移,是
  2026 上半年本身較難分(與首版年內逐月「7 月最弱」不同,兩者的訓練期不同)。
- **fund / prop_self 跨年 < 0.53**:與年內結論同(無區分力),更穩了。
- **prop_hedge 0.59 / 0.57**:弱但方向存在,與卡四(控規模後 +0.05-0.08)同向。
- 兩家 2025 退出的席位單獨看:法興 0.633 / 0.639(n=132)、匯立 0.725 / 0.551
  (n=192)——與 cohort 內四家小額台(0.656 / 0.594)同一量級。**匯立在獨立
  期就已經像「小額台」而不像大五家**,這與 user 對它的描述一致。
- β_mkt ≈ 1.0-1.1 兩年皆是:「外資向量幾乎是市場向量的一比一平移」跨年成立。

### 對 T4 v3 schema 的影響

無欄位增減。變的是**校準卡上要寫的數字**:外資桶的殘差 AUC 應報「年內 0.83
/ 跨年 0.75-0.82」兩個,不能只報年內;殘差係數若要凍結給 as-of 產品,**應
以最近一年估、逐年重估**,不合併估(截距隨市況移動)。
