# v3 Phase 2:Trait / 共同日狀態 / 席位特有異常(2026-09-20)

依 ws-quant `docs/actor_layer_v3_architecture_alignment_2026-09-18.md` §6。
腳本 `v3_phase2_trait_state.py`,純分解邏輯在 `measure/decompose.py`。
資料同 Phase 1(2026 前 170 日,普通股 universe,139,344 分點日)。

## 0. 模型與估計順序(**先宣告,不得事後改**)

\[
X_{b,t}=\mu+f(\log G_{b,t},\,B_{b,t})+\alpha_b+\gamma_t+\varepsilon_{b,t}
\]

- \(f\):**分箱均值**(log_gross 6 箱 × n_symbols 7 箱 = 42 格),不假設函數形式。
- \(\alpha_b\) 席位固定效果、\(\gamma_t\) 共同日效果:交替投影(alternating
  projections)聯合估計至收斂,**不是各自估一次再相減**(§6 明令)。
- 母體:全部 139,344 分點日,**等權**(每個分點日一票)。流量加權版另報為
  敏感度,不當主結果——等權回答「典型分點日」,流量加權回答「典型一塊錢」。
- 不平衡面板:分點活躍日數 1~170 不等。主結果用全體;另報 ≥60 活躍日子集。
- **變異占比不強制加總為 100%**:設計非正交(大席位系統性碰更多股票),
  各成分的增量 R² 依順序而變。故**同時報兩個順序**:
  - 順序 A(宣告的主順序):f(size,breadth) → \(\alpha_b\) → \(\gamma_t\)
  - 順序 B(敏感度):\(\gamma_t\) → \(\alpha_b\) → f(size,breadth)
  兩序差距大的成分,代表它與其他成分共線,結論須帶此但書。

### 一個會計事實先講明(§6 點名)

全市場買量恆等於賣量,所以**不存在「今天全市場都在賣」這種共同淨方向**。
`directional_ratio` 的 \(\gamma_t\) 若存在,意義只能是「今天各席位的淨部位
**離散度**有多大」(有人大買、有人大賣 = 高;大家都平盤進出 = 低),
不是共同方向。預期與解讀一律用離散度措辭。

## 1. 預期(2026-09-20 凍結,跑數據前)

### E1 各 primitive 的三段分解

| primitive | 預期 f(size,breadth) | 預期 \(\alpha_b\) | 預期 \(\gamma_t\) | 預期殘差 |
|---|---|---|---|---|
| top5_share | 20-30%(Phase 1 見強單調) | 25-35% | **<5%** | 35-50% |
| directional_ratio | 5-15% | 15-25% | **10-25%** | 45-70% |
| cos_market_buy | 30-40%(最強機械成分) | 20-30% | <5% | 30-45% |

理由:Phase 1 的 between 已含 f 的貢獻(大席位碰更多股票→機械上較不集中),
所以 f 抽離後 \(\alpha_b\) 會比 Phase 1 的 between 低。\(\gamma_t\) 我押
directional_ratio 最大(事件日的分點分歧度應該真的會跳),另兩個很小
(集中度與像市場度沒有明顯的全市場共同節奏)。

### E2 trait / state 判定

- top5_share、cos_market_*:**mixed 偏 trait**(\(\alpha_b\) > 殘差的一半)。
- directional_ratio:**state**(殘差 + \(\gamma_t\) 合計 > 70%)。

### E3 \(\gamma_t\) 本身是有意義的市場狀態

- directional_ratio 的 \(\gamma_t\) 序列應在**大量事件日出現尖峰**;
  與當日全市場成交量的 Spearman > 0.3。
- 若 \(\gamma_t\) 與成交量幾乎無關(|ρ| < 0.1),代表它抓到的不是事件強度,
  需另尋解釋,且不得直接命名為「市場分歧度」。
- 2026-05-05 / 07-17(A6 的 TEJ vol 異常日)**不影響本 Phase**——分解不用 V。

### E4 順序敏感度

- f 與 \(\alpha_b\) 共線最嚴重(席位規模是席位屬性),預期兩序之下
  f 的增量 R² 差距 > 10 個百分點;\(\gamma_t\) 因與席位維度近乎正交,
  兩序差距應 < 3 個百分點。
- 若 \(\gamma_t\) 兩序差距也很大,代表日效果與席位組成混淆(當日活躍席位
  組成改變),需在結論中降級。

### E5 席位特有異常(\(\varepsilon\))的可用性

- \(\varepsilon\) 的分點內自相關應**接近 0**(< 0.15):若仍高,代表 \(\alpha_b\)
  沒吃乾淨(席位性格隨時間漂移),需要滾動 baseline 而非單一固定效果。
- **這條是給下游的規格**:若自相關高,則 state 必須用滾動窗定義,
  單一年度固定效果不可用於 as-of 產品。

## 2. 結果(2026-09-20,139,344 分點日 / 879 席位 / 170 日 / 35 個條件化格)

### 2.0 一個施工錯誤先講(已修)

首版 `max_iter=50` **未收斂就靜默回傳**。真實面板需 **324-348 次**迭代
(f 與 α 高度共線時,交替投影是在兩者間慢慢重分配)。未收斂的後果是
**低估 α**:top5_share 的 α 占比 71.9%(50 次)vs 78.3%(收斂值)。
殘差 ε 很早就穩定(兩者皆 31.4%),所以 trait/state 的**判定結論不受影響**,
但 f/α 的切分會錯。已改為上限 1,000 次且**未收斂一律 raise**,加回歸測試
(用不平衡面板——平衡面板一輪就收斂,測不出來)。

### 2.1 三段分解(收斂值;成分自身變異/總變異,非正交故不加總)

| primitive | f(size,breadth) | α_b 席位 | γ_t 共同日 | ε 殘差 | 判定 |
|---|---|---|---|---|---|
| top5_share | 29.8% | **78.3%** | 11.3% | 31.4% | **trait 為主** |
| cos_market_buy | 4.3% | **59.3%** | 14.1% | 39.6% | mixed 偏 trait |
| cos_market_sell | 4.6% | **57.8%** | 13.7% | 43.3% | mixed 偏 trait |
| directional_ratio | 2.3% | 24.1% | 14.9% | **59.4%** | **state 為主** |

順序敏感度(增量 R²,順序 A = f→α→γ vs 順序 B = γ→α→f):

| primitive | f 兩序差 | α 兩序差 | **γ 兩序差** |
|---|---|---|---|
| top5_share | 38.5pp | 38.6pp | **1.5pp** |
| directional_ratio | 15.5pp | 16.2pp | **0.5pp** |
| cos_market_buy | 27.7pp | 30.4pp | **0.1pp** |
| cos_market_sell | 26.0pp | 29.5pp | **1.2pp** |

**f 與 α 嚴重共線**(兩序差 15-39pp),因為席位規模本身就是席位屬性——
「這是機械效果還是性格」在資料上分不開,只能兩序並陳。**γ 幾乎正交**
(兩序差 ≤1.5pp),所以日效果的估計是穩健的,可以單獨引用。

敏感度(≥60 活躍日子集):四個 primitive 的占比變動皆 <0.5pp,不平衡面板
不是結論來源。

### 2.2 逐條對照凍結預期

| 預期 | 實際 | 判定 |
|---|---|---|
| E1 top5_share:f 20-30% / α 25-35% / γ<5% / ε 35-50% | 29.8 / **78.3** / **11.3** / 31.4 | f 料中,**α 與 γ 打臉** |
| E1 directional:f 5-15% / α 15-25% / γ 10-25% / ε 45-70% | 2.3 / 24.1 / 14.9 / 59.4 | **除 f 外全料中** |
| E1 cos_market:f 30-40% / α 20-30% / γ<5% / ε 30-45% | 4.3 / **59.3** / **14.1** / 39.6 | **f、α、γ 三項全打臉**,僅 ε 料中 |
| E2 top5/cos 為 mixed 偏 trait | 成立(α 遠大於 ε 的一半) | 料中 |
| E2 directional 為 state(γ+ε>70%) | 74.3% | 料中 |
| E3 γ(directional)與市場量 ρ>0.3 | **−0.27(反向)** | **打臉** |
| E4 f/α 兩序差 >10pp | 15-39pp | 料中 |
| E4 γ 兩序差 <3pp | 0.1-1.5pp | 料中 |
| E5 ε 自相關 <0.15 | directional 0.064 ✓;cos_sell 0.158、cos_buy 0.191、top5 **0.271** ✗ | **半數打臉** |

**三個打臉的意義**:

1. **我把「機械成分」與「席位性格」搞反了**(cos_market)。Phase 1 看到
   cos_market 對 breadth 強單調上升,我推論它主要是機械效果(預期 f 30-40%)。
   收斂後 f 只有 4.3%,α 高達 59.3%——**同規模同廣度的席位之間,「像市場」
   的差異極大**。也就是說 Phase 1 的單變量條件表看到的單調性,絕大部分是
   「大席位恰好也是那些長期就像市場的席位」,而不是規模本身逼出來的。
   這翻轉了 Phase 1 §2.3 的措辭:cos_market 的 raw 值仍不可直接讀,但要扣的
   主要是**席位自身基線**,不是 size/breadth。
2. **γ_t 普遍比我想的大**(11-15%,不是 <5%)。四個 primitive 都有一成以上
   的共同日節奏,且 γ 的估計穩健(兩序差 ≤1.5pp)。這支持 §6「日效果是有
   意義的共同狀態,不因估計席位異常就消失」——它該當產品輸出,不是殘渣。
3. **ε 的自相關沒降到可用水準**(top5 0.271、cos_buy 0.191)。原始 y 的
   自相關 0.72/0.58 已大幅降低,但仍非白噪音,代表**席位性格會漂移**,
   單一年度的固定 α_b 吃不乾淨。→ **給下游的硬規格:state 必須用滾動窗
   baseline 定義,年度固定效果不可用於 as-of 產品。** directional_ratio
   是唯一例外(0.064),它的 α 用固定效果就夠。

### 2.3 γ_t 是什麼(E3 打臉後的實際樣貌)

| primitive | γ 的 sd | corr(γ, 當日市場量) | corr(γ, 當日活躍席位數) |
|---|---|---|---|
| top5_share | 0.035 | **−0.567** | +0.156 |
| directional_ratio | 0.032 | **−0.269** | −0.025 |
| cos_market_buy | 0.062 | +0.332 | −0.196 |
| cos_market_sell | 0.062 | **+0.421** | −0.048 |

**方向與我預期相反**:淨部位離散度(directional 的 γ)在**低量日較高**,
不是高量日。集中度的 γ 更明顯(−0.57):**量小的日子,各席位的錢更集中在
少數股票、彼此的淨部位更分歧**;量大的日子則相反——大家一起湧向同一批
熱門股,配置更像市場(cos_market 的 γ 與量正相關 +0.33/+0.42)。

用一句話說:**成交量大的日子,市場行為同質化;量小的日子,各席位各做各的。**
這是描述,不是機制——為什麼如此(題材集中度?法人參與度?)未驗證。

directional_ratio 的 γ 最高日:2026-03-09、07-17、07-31、04-08、07-28;
最低日:05-27、05-12、05-05、06-02、06-01(皆為 3.2-3.9 兆的大量日)。
07-17 同時是 A6 的 TEJ vol 異常日,但**本 Phase 的分解完全不用 V**
(市場量取自 T1 加總),故不受該資料問題污染。

## 3. 對下游的規格(驗收項)

1. 每個 primitive 的 trait/state 標記:**top5_share = trait 為主、
   cos_market_* = mixed 偏 trait、directional_ratio = state 為主**。
2. **state 的定義必須用滾動窗**(ε 自相關 0.16-0.27),年度固定效果只可用於
   回溯描述,不可用於 as-of 產品。directional_ratio 例外(0.064)。
3. **γ_t 應作為市場層級輸出**(四條序列),估計穩健(兩序差 ≤1.5pp)。
4. f 與 α 在資料上不可分(兩序差 15-39pp),**任何「扣掉規模效果」的說法
   都必須同時聲明扣除順序**,否則同一份資料能講出兩套相反的故事。
