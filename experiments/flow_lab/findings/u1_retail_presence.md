# U1/U1b/U2 散戶在處置期間的存在感(2026-09-14,紅隊修正後定稿)

**起點**: user 提問「處置期間散戶會不會不見?」。腳本:`u1_retail_presence.py` /
`u1b_runup_gap.py` / `u2_retailization_arm.py`;紅隊獨立重算:`redteam_u1_core.py` /
`redteam_u1_analysis.py`(向量化重建,基線逐格對齊後五路攻擊)。
預期先行記 progress.json U1/U1b/U2 條目。定義 = 兩套正典並陳
(taxonomy cluster C0+C3;name-based retail cohort),無自創定義。

## 定稿結論(含紅隊修正)

1. **散戶不但沒不見,典型處置事件裡市場更散戶化**(紅隊 CORRECTED 後保留):
   事件中位數 baseline 63%→dispo 66%(cluster 版)/72%→78%(cohort 版);
   去污染(+3.8~8pp)與 first-event 去重(+4.9pp)後**更強**;覆蓋率 artifact
   排除(全覆蓋 cohort 版效應更大)。**但書(紅隊攻擊3)**:這是「典型(中小型)
   事件」事實,**不是金額加權事實**——金額 pooled 反轉(-5.7pp):前 10 大
   處置事件(晶片權值股)佔處置期總金額 19.4%,其中 7/10 的 HQ 金額份額 >47%,
   大型事件處置期反而更機構化。引用本結論必須帶此但書。
2. **「處置沒量」不只是錯覺——處置期其實比真正的平常日更熱**(紅隊最大修正):
   原讀數 dispo=baseline 的 87% 是 baseline 窗污染假象——35.7% 事件的
   baseline [sg-40,sg-21] 撞上同股另一次處置的高量期,把分母灌水。去污染後
   dispo 每日成交 = 真安靜期的 **1.85×**(first-event 版 2.43×,新制 1.02×)。
   體感的「沒量」全部來自與 run-up(3.2×)的對比。
3. **退場的機構幾乎全是外資(典型事件)**:外資 HQ 12.1%→6.7% 腰斬,解禁後
   立刻彈回 12.5%;本土 HQ 僅 15.9%→14.1%。彈回的精準度指向**作業性退場**
   (預收款券/分盤對 swap/程式/避險流程的摩擦),非觀點。同但書:大型晶片
   事件例外(機構金額份額反升)。run-up 的推手是本土 HQ(+1.9pp)與 C2 中型
   主力(+1.0pp),外資 run-up 反而 -1.4pp。
4. **C1 虎尾幫**(紅隊 CONFIRMED):在處置股 baseline 就只有 0.43%,處置期
   0.49% 無進一步消失——「虎尾幫不碰處置股」精確版=「不碰這類股」;
   解禁後絕對量 2.8-2.9×(與 F4 surge 一致)。
5. **run-up 散戶份額低於 baseline**(紅隊 CONFIRMED,五攻擊全穩):
   63.0%→60.4%,發動段被機構/主力稀釋。
6. **附帶(紅隊攻擊4 副產品)**:處置候選股在「遠離任何事件的平常日」散戶
   份額就有 49-54%(全市場口徑下已異常高),且 baseline 窗(60-66%)比自身
   無事件期更散戶化——**散戶化在事件前就開始爬坡**,baseline 窗本身已非
   「正常市場」;所有階段對比都該帶此外部效度但書。

## 可交易性:null,關死(U2)

處置窗散戶化程度 → 右臂,單一鎖定定義、強制關卡一次跑齊:
all IC=-0.073(p=0.21)/ clean -0.040 / first-event 去重 -0.031 /
去重+clean **+0.046(翻號)**。「誰在場上」家族 8 測 8 死。
本題同時是強制關卡的展示案例:all→去重+clean 的縮水與翻號,再次示範
慣犯股重複抽樣的膨脹方向。

## 對機制拼圖的增量

- 處置期 = 外資集體作業性缺席、對手盤散戶化的市場;少數逆向留守收貨的
  外資(JPM 型)因此顯眼。
- 「外資拉抬→處置」敘事在份額上不成立(run-up 主力是本土通道)。
- 規則監控清單新增一條:**預收款券**是外資參與的開關——這條規則若動,
  外資行為(與依附其上的一切統計)立刻翻轉。
- baseline 窗污染(35.7%)是 methodology 級教訓:處置慣犯股的任何
  「事件前基準」都必須先驗證不撞同股他事件,否則分母被灌水。
